# Feature Request: File attachment support in Claude mobile app

## Current Behavior
In the Claude mobile app, when using the Code feature and tapping the + button in the chat, only image/photo attachments are supported. General files (PDF, text files, code files, etc.) cannot be attached directly.

## Desired Behavior
Allow users to attach various file types from the mobile device's file system, similar to the desktop/web version functionality.

## Use Case
- Attaching code files for review and debugging
- Uploading configuration files (JSON, YAML, etc.)
- Sharing log files for troubleshooting
- Attaching documentation (PDF, TXT, MD, etc.)

## Current Workarounds
1. Taking screenshots of code
2. Copy/pasting text manually
3. Switching to desktop/web version

## Additional Context
This limitation significantly reduces the usability of Claude Code on mobile devices, especially for developers who need to work on-the-go.

**Platform**: Mobile app (iOS/Android)
**Feature**: Claude Code chat interface
