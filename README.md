# jwl
codingtest

## 프로젝트 구조

```
jwl/
├── problems/           # 알고리즘 문제 풀이
│   ├── two_sum.py
│   └── binary_search.py
├── data_structures/    # 자료구조 구현
│   └── stack.py
└── README.md
```

## 실행 방법

각 파일을 개별적으로 실행할 수 있습니다:

```bash
# Two Sum 문제
python problems/two_sum.py

# Binary Search
python problems/binary_search.py

# Stack 자료구조
python data_structures/stack.py
```

## 포함된 내용

### 알고리즘 문제
- **Two Sum**: 해시맵을 이용한 O(n) 솔루션
- **Binary Search**: 반복문/재귀 두 가지 방식

### 자료구조
- **Stack**: LIFO 구조, 괄호 균형 검사 예시 포함

## 학습 목표

- 자료구조 직접 구현해보기
